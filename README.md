# Postoperative AKI prediction: does sample size determine the algorithm?

Two-cohort study (VitalDB + INSPIRE, Seoul National University Hospital) comparing
logistic regression vs XGBoost for preoperative AKI prediction across a 37-fold
difference in sample size. Manuscript under review at BMC Medicine.
